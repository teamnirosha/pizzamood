# USP, FOMO and Enquiry Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the 7 USPs and the "one outlet per area" rule impossible to miss (hero, a USP section, strips on key pages), add a floating WhatsApp bubble and the franchise phone, and add matching JSON-LD.

**Architecture:** One content module `lib/usps.ts` (USPs, exclusivity line, phone, WhatsApp link) feeds small presentational components and the schema generators in `lib/seo.ts`. Scarcity is the real area-exclusivity rule only: no timers, no invented counts.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind 4, lucide-react. No test runner: checks are plain `node` scripts (Node 24 runs `.ts` imports from `.mjs`).

**Spec:** `docs/superpowers/specs/2026-10-15-usp-fomo-design.md`
**Builds on:** `lib/pricing.ts` (branch `feat/kiosk-cafe-pricing`). Work on that branch.

**Deviations from the spec (found while reading the code)**
- The Navbar already has a top banner (phone + "Check City Availability"). Instead of a new `ScarcityBar`, the banner's text becomes the exclusivity line. Fewer parts, same effect.
- `FranchiseInvestmentSection` clicks `#open-franchise-modal`, but no element has that id anywhere, so that click does nothing today (existing bug, out of scope). New buttons follow the Hero's pattern instead: each owns its `FranchiseModal` state, via one small `EnquiryButton` component.
- Schema is verified by parsing the rendered JSON-LD from the running site (`scripts/check-jsonld.mjs`), because `lib/seo.ts` cannot be imported by plain `node` (it uses the `@/` alias).
- Existing copy says "Target launch" and "as little as 30 days*". It is changed to "Guaranteed 30-day go-live" so the site does not contradict itself.

**Notes before starting**
- `AGENTS.md` warns this Next.js has breaking changes. This plan adds only plain components, `<script type="application/ld+json">` tags (already used in this repo) and string edits. If a build error mentions a Next API, read `node_modules/next/dist/docs/` first.
- Icon names below are for lucide-react v1.x. If `tsc` says one does not exist, pick the closest lucide icon and say so in the report.
- Do NOT edit `data/enquiries.json`.
- Use quoted text, not line numbers, to find edits.

import assert from "node:assert/strict";
