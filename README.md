# Pizza Mood Franchise Website

Official website and franchise enquiry portal for Pizza Mood QSR.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Database**: MongoDB (Mongoose)

## Features
- **Franchise Enquiry System**: Direct WhatsApp & Database lead collection.
- **Outlets Directory**: Dynamic location pages and local SEO hubs.
- **Admin CRM**: Password-protected lead and outlet management portal.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Building for Production

```bash
npm run build
npm start
```
